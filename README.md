# PyLang - Простой язык программирования с Python-подобным синтаксисом

PyLang - это легкий язык программирования с простым Python-подобным синтаксисом, управлением памятью и процессами.

## Особенности

- ✨ **Python-подобный синтаксис** - простой и понятный
- 🧠 **Управление памятью** - выделение, освобождение, проверка утечек
- ⚙️ **Управление процессами** - создание, чтение кода, завершение
- 📦 **Легковесный** - минимальные зависимости
- 🚀 **Быстрый** - компилируется в нативный код

## Установка

```bash
# Компиляция
go build -o pylang.exe

# Или для Linux/Mac
go build -o pylang
```

## Использование

```bash
# Запуск программы
pylang examples/hello.pyl

# Демонстрация управления памятью
pylang examples/memory_demo.pyl

# Демонстрация управления процессами
pylang examples/process_demo.pyl

# Функции и циклы
pylang examples/functions.pyl
```

## Синтаксис

### Базовые операции

```python
# Вывод
print("Hello, World!")

# Переменные
x = 10
name = "PyLang"

# Математика
result = x + 20
power = 2 ** 8
```

### Условия

```python
if x == 10:
    print("x равен 10")
else:
    print("x не равен 10")
```

### Циклы

```python
# Цикл for
for i in range(0, 10):
    print(i)

# Цикл while
counter = 5
while counter > 0:
    print(counter)
    counter = counter - 1
```

### Функции

```python
def greet(name):
    print("Привет")
    print(name)
    return 42

result = greet("Мир")
```

### Управление памятью

```python
# Выделение памяти
mem_alloc(buffer, 1024)

# Освобождение памяти
mem_free(buffer)

# Проверка состояния памяти
mem_check()
```

### Управление процессами

```python
# Создание процесса
proc_create(worker, "code.pyl")
pid = last_proc_id

# Чтение кода процесса
proc_read(pid)

# Завершение процесса
proc_kill(pid)

# Список всех процессов
proc_list()
```

## Встроенные функции

- `print(value)` - вывод значения
- `input()` - ввод с клавиатуры
- `int(value)` - преобразование в целое число
- `float(value)` - преобразование в число с плавающей точкой
- `str(value)` - преобразование в строку
- `len(string)` - длина строки

## Операторы

### Арифметические
- `+` - сложение
- `-` - вычитание
- `*` - умножение
- `/` - деление
- `%` - остаток от деления
- `**` - возведение в степень

### Сравнения
- `==` - равно
- `!=` - не равно
- `<` - меньше
- `>` - больше
- `<=` - меньше или равно
- `>=` - больше или равно

    result = 1
    for i in range(1, n):

## Архитектура

PyLang использует следующую архитектуру:

1. **Лексер** (`lexer.go`) - токенизация исходного кода
2. **Парсер** (`parser.go`) - построение AST
3. **AST** (`ast.go`) - абстрактное синтаксическое дерево
4. **Интерпретатор** (`interpreter.go`) - выполнение программы
5. **Менеджер памяти** (`memory.go`) - управление памятью
6. **Менеджер процессов** (`process.go`) - управление процессами
